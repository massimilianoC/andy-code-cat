# Skill: Anti AI-Slop UI Review

Use this skill as a final design pass for any generated visual artifact.

## Core Directive

Remove the visual tells of generic AI output: flat hierarchy, default spacing, interchangeable cards,
weak typography, timid colors, decorative gradients without purpose, and identical section rhythm.

## Review Pass

- Identify the focal point of each major screen. If there is none, create one.
- Replace generic section titles with specific, audience-aware language.
- Break repetitive card grids with featured cards, asymmetry, grouping, or narrative rhythm.
- Increase contrast between primary and secondary content.
- Remove decorative elements that do not clarify mood, hierarchy, or interaction.
- Avoid default blue/purple SaaS palettes unless explicitly requested.
- Ensure motion has a reason: entrance, focus, feedback, or spatial orientation.

## Output Checks

- The artifact does not look like a default AI landing/dashboard template.
- The first viewport has a memorable composition.
- Typography choices feel intentional rather than browser-default.
- Every decorative layer supports a specific mood or message.
