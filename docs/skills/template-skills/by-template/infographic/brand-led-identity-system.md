# Skill: Brand-Led Identity System

Use this skill when the artifact needs a strong, coherent visual identity across pages, slides,
posters, or campaigns.

## Core Directive

Create a small identity system inside the artifact. The output should feel like it belongs to one
brand, not like unrelated components assembled together.

## Identity Rules

- Define a recognizable palette with primary, secondary, neutral, and accent roles.
- Use one repeatable graphic motif: frame, badge, linework, symbol, pattern, crop, gradient, or grid.
- Keep typography consistent: display role, body role, label role, numeric/data role when needed.
- Repeat visual signatures across sections without making every block identical.
- Make image treatment consistent: crop ratio, mask shape, overlay style, border/radius, or caption system.
- Use logo/brand placeholder areas deliberately if no real brand asset exists.
- Make exports and screenshots look coherent even outside the full page context.

## Output Checks

- A section screenshot is still recognizable as part of the same artifact.
- The identity system can scale to another page or slide.
- Colors and type are roles, not isolated choices.
- The artifact has a visible brand point of view.
