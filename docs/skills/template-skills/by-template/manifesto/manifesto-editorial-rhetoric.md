# manifesto-editorial-rhetoric

Applies to: `presetIds: manifesto`, `tags: brand, statement, editorial`

Use this skill when generating manifestos, value statements, public declarations, and
identity-driven editorial artifacts.

## Goal

The artifact must express a strong position. It is not a sales page and not a generic about page.

## Required Structure

- Opening claim with a memorable title or sentence.
- Thesis: what the project believes and why it matters now.
- Antagonist/problem: what is being rejected, corrected, or replaced.
- 5-7 principles with short operational explanations.
- Vision: the future state being built.
- Commitments: what the project promises to do.
- Signature: brand/person/date/place or symbolic closing.

## Writing Rules

- Use concise, declarative language.
- Make every principle actionable.
- Use repetition, contrast, and rhythm sparingly but intentionally.
- Prefer conviction over generic inspiration.

## Visual Rules

- Strong typography and contrast.
- Editorial spacing.
- Few decorative elements unless they reinforce the message.

## Avoid

- Corporate boilerplate.
- Abstract values with no behavior attached.
- Too many CTAs.
- Marketing claims that weaken the manifesto tone.

## Acceptance Checks

- The artifact clearly states what it stands for.
- Principles can guide decisions or behavior.
- The final section feels like a commitment, not a footer.
