# Skill: Product Interface Craft

Use this skill for websites, dashboards, forms, and product-like web apps where UI quality matters.

## Core Directive

Design the interface as a working product surface with hierarchy, states, and interaction clarity.
Do not stop at visual alignment; make the interface feel operated, inspectable, and trustworthy.

## Craft Rules

- Establish a clear information hierarchy: primary action, current state, secondary actions, supporting detail.
- Give every interactive element a state: default, hover/focus, active/selected, disabled, empty, error, success.
- Use spacing as structure: related controls stay close, unrelated regions get real separation.
- Make dense content scannable with labels, grouping, microcopy, and progressive disclosure.
- Prefer fewer stronger components over many equal-weight panels.
- Use realistic data examples and edge states; avoid empty fake dashboards with meaningless metrics.
- Preserve accessibility: focus order, label clarity, keyboard-reachable controls, contrast.

## Output Checks

- A first-time user knows where they are, what changed, and what to do next.
- Empty/error/loading/success states are designed, not accidental.
- Visual hierarchy still works when all text is replaced with grey blocks.
- The UI does not rely on color alone to communicate status.
