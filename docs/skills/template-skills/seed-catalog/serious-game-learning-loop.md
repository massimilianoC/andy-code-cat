# serious-game-learning-loop

Applies to: `presetIds: seriousgame`, `tags: learning, simulation, training`

Use this skill when generating educational games, training simulations, compliance exercises,
or interactive learning artifacts.

## Goal

The game mechanic must reinforce a learning objective. Scoring is secondary to feedback.

## Required Structure

- Learning objective stated in user-facing language.
- Scenario that creates a meaningful decision context.
- Challenge loop: quiz, branching choice, simulation, task, matching, or micro-mission.
- Immediate formative feedback after each action.
- Progress indicator: mastery, score, badge, level, or completion.
- Final debrief with strengths, mistakes, and next steps.

## Feedback Rules

- Explain why an answer/action is correct or incorrect.
- Give actionable correction, not only "wrong".
- Tie feedback to the learning objective.

## Game Rules

- Keep interactions simple enough that the lesson stays central.
- Use consequences to make choices meaningful.
- Let the user retry or improve after mistakes.

## Avoid

- Quiz-only screens with no context.
- Scores without explanation.
- Game mechanics unrelated to the learning outcome.
- Punitive failure states that stop learning.

## Acceptance Checks

- Every interaction teaches or reinforces one objective.
- Feedback appears after each meaningful choice.
- Final debrief summarizes what the user learned.
- User can retry without reloading the page.
