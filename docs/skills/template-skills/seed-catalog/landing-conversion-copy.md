# landing-conversion-copy

Applies to: `presetIds: landing`, `tags: conversion, cta, lead-gen`

Use this skill when generating a conversion-oriented landing page.

## Goal

The artifact must guide one visitor segment toward one primary action. It is not a generic
company website.

## Required Structure

- Hero with offer, measurable promise, target audience, trust microcopy, and primary CTA.
- Problem section that names the user's pain, urgency, and cost of inaction.
- Solution section with 3-5 benefits phrased as outcomes.
- Proof section: testimonials, customer logos, metrics, guarantees, or credible placeholders.
- Offer/process section that explains what happens after the CTA.
- Objection-handling FAQ.
- Final CTA that repeats the same action.

## Copy Rules

- Keep the headline concrete and audience-specific.
- Use benefits before features.
- Every section must either increase desire, reduce risk, or clarify the next step.
- Use one primary CTA label consistently.

## Avoid

- Multiple competing CTAs.
- Generic "about us" sections that do not support conversion.
- Feature lists without user outcomes.
- Empty proof claims such as "trusted by many" without examples or placeholders.

## Acceptance Checks

- The primary CTA is visible above the fold.
- The page can be understood in 30 seconds.
- Each section supports the same conversion goal.
- FAQ answers at least price/time/risk/support or equivalent objections.
