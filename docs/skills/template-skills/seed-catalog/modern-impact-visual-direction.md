# Skill: Modern Impact Visual Direction

Use this skill when the artifact must feel current, intentional, and visually memorable rather
than like a generic generated page.

## Core Directive

Pick one strong visual direction and execute it consistently. Do not mix many weak motifs.
The output should have a clear point of view in typography, spacing, contrast, imagery, and motion.

## Required Decisions

- Define one dominant mood: editorial, cinematic, tactile, technical, playful, luxury, brutalist, or calm.
- Use a distinctive type scale: one expressive display treatment plus one readable body rhythm.
- Create a strong first screen with a focal object, asymmetric composition, or bold spatial tension.
- Use color with intent: one dominant background system, one accent family, and restrained neutrals.
- Avoid default SaaS sameness: no generic centered hero, no identical cards grid, no timid pastel accents.
- Use subtle atmospheric depth: gradients, grain, large shapes, oversized typography, image masks, or spatial layers.
- Add 1-3 meaningful animations only when they clarify hierarchy or create arrival energy.

## Output Checks

- The design is recognizable from a screenshot at 25 percent size.
- The top section has a clear visual anchor before reading the text.
- Cards, sections, and CTAs do not all share the same weight.
- The visual system could plausibly become a brand direction, not just a layout.
